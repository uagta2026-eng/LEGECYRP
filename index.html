1. RP / NON-RP

1.1. Основні терміни

NonRP — дії, які суперечать логіці або атмосфері рольової гри.

RDM (Random DeathMatch) — безпричинне масове або хаотичне вбивство/напад на гравців.

DM (DeathMatch) — напад або використання зброї проти гравця без достатньої RP-причини.

MG (MetaGaming) — використання інформації, отриманої поза грою, у RP-ситуації.

PG (PowerGaming) — нереалістичні дії або нав'язування іншому гравцю результату RP-ситуації.

FearRP — ігнорування загрози життю персонажа. Гравець повинен враховувати небезпеку для свого персонажа.

Combat Log — вихід із гри під час активної RP-ситуації, переслідування, затримання або бою.

Cuff Rush — миттєве використання наручників без нормальної RP-взаємодії.

RK (Revenge Kill) — помста гравцю після смерті/відродження персонажа без RP-підстави.

Bunny Hop / Bhop — серійні стрибки для отримання переваги. Дозволені в межах ігрової механіки, але заборонено використовувати їх для навмисного зриву RP.

1.2. RP-команди

Команди /me, /do використовуються для опису RP-дій та ситуацій.

Заборонено використовувати RP-команди для обману, нав'язування результату іншому гравцю або отримання нереалістичної переваги.

1.3. Покарання

За RP-порушення адміністрація може застосувати: попередження, депорт або бан.

DM — бан від 2 діб.

RDM — бан від 5 діб.

Покарання: тюремний строк та конфіскація зброї.

2.3. Неправомірне використання зброї

Заборонено стріляти, нападати на інших гравців, стріляти в повітря або використовувати зброю для залякування.

Покарання: тюремний строк та можливий штраф до 8 000€.

«Масове або хаотичне використання зброї без RP-причини додатково розглядається як RDM.»

Покарання: конфіскація зброї, штраф до 16 000€ або депорт до 3 діб.

2.4. Передача зброї

Заборонено передавати, продавати зброю іншим гравцям.

Покарання: конфіскація зброї, тюремний строк.

2.5. Зброя у зелених та безпечних зонах

Заборонено діставати, демонструвати або використовувати зброю у зелених/безпечних зонах без обґрунтованої RP-причини.

Покарання: депорт до 3 діб. У випадку стрільби або масового порушення додатково може застосовуватися покарання за DM/RDM.

2.6. Вибухові засоби

Заборонено використовувати вибухові засоби без RP-причини, у зелених зонах або для навмисного зриву RP-ситуацій.

Покарання: тюремний строк, конфіскація. Масове використання вибухівки може каратися баном до 7 діб.
